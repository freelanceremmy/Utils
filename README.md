# Temperature Converter

Live demo: https://freelanceremmy.github.io/Utils/

Ever heard it's over a hundred degrees and got confused? This fixes it.

## Features
- Fahrenheit to Celsius
- Celsius to Fahrenheit
- Live conversion, no button needed


## How to use
1. Enter value in °F to get °C
2. Or enter value in °C to get °F

## Tech
HTML, CSS, JavaScript
